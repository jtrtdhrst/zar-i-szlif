# Product MCP — Żar i Szlif

Ten katalog jest **jedynym** miejscem na kod MCP **specyficzny dla aplikacji Żar i Szlif**: karty zbiórek, plany, zadania, stopnie i sprawności oraz autoryzowane operacje na danych produktu.

Nie umieszczaj tu ogólnych serwerów/integracji MCP do Ubuntu, Mautic, Emailens, Paperclip, Coolify, ComfyUI, Plasmic, Qdrant, Supabase, Playwright czy Hermes Gateway. Ich kanoniczne źródło: `miloszspyrka-code/harness-zar-i-szlif`.

`posthog.server.mjs` jest opcjonalnym modułem analityki, **nie** implementacją całego serwera MCP. Nie włączaj zbierania danych wejściowych narzędzi, tokenów, promptów ani danych dzieci.
