# Stan braku danych

Gdy API nie jest podłączone lub brak danych roboczych wymaganych w karcie: nie wymyślać treści, nie podmieniać placeholderem „uzupełnij gdzie indziej”. Pokazać jawną, nieblokującą pustkę + edytowalne pole / roboczy opis użytkownika. Stosować tabele z nagłówkiem + wiersze edytowalne. Dla sprawności: `Brak danych` + możliwość ręcznego opisu. Karta pozostaje samowystarczalna; źródło opisywane tylko w dokumentacji, nie w UI.
