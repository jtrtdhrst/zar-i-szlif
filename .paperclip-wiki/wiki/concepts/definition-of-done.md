# Definition of Done

**Write task**: isolated workspace poprawny → implementacja kompletna → odpowiednie testy → commit → push → commit SHA → jasna dyspozycja issue.

**Blocked task**: zapis `BLOCKER / OWNER / EXACT ACTION`. Znany bloker zewnętrzny → czekanie pasywne, bez pętli recovery. Nie kończyć runa bez jawnej dyspozycji. Maks 2 aktywne deliverable; nowe issue = nowy, niezależnie wartościowy deliverable.
