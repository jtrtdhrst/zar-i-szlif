# PRD Kompas Zbiórek v1.7

Cel: pomoc liderowi Royal Rangers planować zbiórki/wyjazdy i prowadzić ~2-tygodniowe cykle doskonalenia (obserwacje→problem→praprzyczyna→hipoteza→próby→wnioski→reguła). Produkt poprawia jakość decyzji, nie decyduje za lidera.

Użytkownik: drużynowy/instruktor znający lokalne warunki, zatwierdzający każdy zapis.

Zakres etui karty zbiórki: dane i obecność, sprawności, eksperyment, przygotowanie, plan godzinowy, refleksja — każdy obszar z kryteriami akceptacji (tabele zadań, planu, wymagań sprawności). Wymagania sprawności z API, nie wymyślane; przy braku API — `Brak danych` + opis roboczy.

Poza zakresem: pełne stopnie RR, automatyczne decyzje, Canvas jako wymóg.

Kryteria akceptacji i definicja gotowości powiązane z Definition of Done z [[wiki/sources/wspolny-kontekst]].
