# Kompas RRP Brand System

Canonical deliverable: the connected Penpot file.

## Sources analyzed

- `ogloszenie.png`: olive/ecru event composition, condensed display type, compass geometry, circular framing.
- `mundur.jpg`: flat instructional drawing, firm outlines, olive/ecru uniform palette, annotation logic.
- `jakis_obrazek.png`: olive field, torn edge treatment, editorial headline hierarchy.
- `fizyczny_alarm_pomar.jpg`: orange alert pictogram; retained only as a signal-color principle, not a core motif.
- `cyferki na tle.png`: rough brush marks beneath large condensed numerals; retained as controlled event emphasis.
- `6.png`: single-line, mint emergency icon; retained as a secondary functional-color reference only.

## Decisions

- Brand core is olive, ecru, red, gold, and ink. Mint is a functional secondary color, not a campaign accent.
- Compass geometry, precise contour lines, and single-color rough brush marks create recognition without the logo.
- Oswald drives strong display hierarchy; Montserrat is the functional UI face; Lora is reserved for short editorial statements.
- Photography is excluded from the brandbook. Use editable shapes, patterns, and flat instructional illustration.

## Penpot organization

- `00 Brand DNA`: principles and signature elements.
- `01 Foundations`: color, type, spacing, and layout tokens.
- `02 Visual Language`: motif, illustration, and background rules.
- `03 Components`: reusable UI components.
- `04 Templates`: social, announcement, landing hero, and content-section patterns.

See `../../../BRAND-DESIGN-SYSTEM.md` for the canonical, complete specification. `tokens/colors_and_type.css`, `brand/style-notes.md`, and `brand/voice-and-tone.md` provide portable implementation guidance.
