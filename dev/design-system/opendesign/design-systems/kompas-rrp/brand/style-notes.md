# Visual Notes

## Composition

Use a clear field-and-paper contrast: one dominant olive field plus one ecru reading field. Align content to a 12-column desktop grid with 72px outer margins. On mobile, use four columns and 20px outer margins.

## Signature Elements

The compass device is a contained focal point. It may use one red directional cue; gold is permitted only as its opposite directional cue in an instructional diagram. Contour lines imply navigation or instruction. Rough brush marks appear only once per composition and sit behind a numeric or event cue.

## Illustration

Build simple, editable, flat objects with black or olive outlines. Use labels and leader lines to explain equipment, clothing, or process. The illustration is a system element, not a decorative scene.

## Surfaces

Avoid gradients, soft shadows, and generic rounded-card styling. Use 1-2px outlines, paper contrast, and layer order to create separation.
