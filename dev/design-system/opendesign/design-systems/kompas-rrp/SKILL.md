# Kompas RRP Brand System

Use this system for Kompas RRP communications and product UI.

- Use `--surface-primary` on broad brand fields and `--surface-canvas` for readable content areas.
- Use Oswald for headings, calls to action, dates, and large numeric events. Use Montserrat for UI and supporting copy.
- Use the compass device once per composition. Do not tile it as decoration.
- Place a single rough brush mark behind a large number or event cue only.
- Keep boards square or near-square. Use `4px` rounding for inputs and buttons; reserve pill shapes for compact tags.
- Do not use photographs in brandbook material. Use editable contour-based instructional illustrations instead.
