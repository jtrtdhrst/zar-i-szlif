# Żar i Szlif — strona WWW

Oddzielny projekt Next.js / TypeScript dla generowania strony WWW przez Plasmic Codegen.

## Integracja Plasmic GitHub (Existing repo)

- Repository: `miloszspyrka-code/zar-i-szlif`
- Branch: `plasmic/website`
- Directory: `app/website`
- Framework: Next.js
- Language: TypeScript
- Mode: Codegen
- Default action: Commit changes

Gałąź `main` jest gałęzią produkcyjną — nie kieruj do niej automatycznych commitów Plasmic.

## Lokalnie

Uruchamiaj polecenia z katalogu `app/website`: `npm install`, `npm run dev`, `npm run build`.

Pierwszy eksport Plasmic może zmodyfikować szablon strony. Przed włączeniem automatycznego wdrożenia wykonaj build i review wygenerowanego kodu.
